Cyber Hero

Security Education Game for Children

Unity 2D, C#, PlayFab, RTLTMPro, ScriptableObjects, Unity Test Framework | Freelance client, released for macOS

  • Built a four-stage educational game solo, giving each stage a different genre so the interaction itself carries the lesson: a password builder driven by dragging characters into slots, a shooter that separates firewall from antivirus, a sorting game on what to keep private, and a quiz gate.
  • Chose composition over inheritance to run three unrelated genres under one progression system, with a persistent GameManager owning hearts, timer, dialogue, and scene flow, and one StageRules component per stage holding only its own logic, so adding the fourth stage required no change to the first three.
  • Built the progression layer shared by every stage: lives, countdown timer, stars and coins awarded on time and accuracy, a cosmetic name-tag shop, and a personalized certificate reporting per-stage times, attempts, and quiz accuracy, with the same figures sent to PlayFab analytics.
  • Authored quiz questions and shop items as ScriptableObject data assets so content is revised without a rebuild, and covered the heart-loss system with EditMode and PlayMode tests.
